# Flipbook Canvas UI 规格

## 目标

做一个与 `flipbook.page` 画布语法一致、但使用盐田场景和本地 mock 数据的前端原型。核心不是复制官网内容，而是复现浏览器外壳、单画面主舞台、点击探索和低干扰控制。

## 视觉基线

- 页面背景：暖白纸张 `#f7f1e3`。
- 浏览器外壳：2px 深色描边、约 29px 圆角、轻微暖色投影。
- 顶栏：约 74px，三个窗口圆点、胶囊搜索框、语义锚点和分享图标。
- 主舞台：占据剩余高度，16:9 视觉构图，画面本身由 Canvas 绘制。
- 画面文字：场景标题和地图文字绘制在 Canvas；交互解释以可关闭浮层显示。
- 颜色：纸张、墨黑、珊瑚红、青绿色、浅水蓝和橄榄色，避免单一色相。

## 交互模型

- 任意坐标点击都会产生一个本地 mock 的场景跳转。
- 命中语义锚点时先打开解释面板，随后进入对应场景；可手动点“进入这个区域”。
- 已访问场景通过返回按钮本地切换，不调用模型。
- `motion` 开关只驱动画面中的水纹/呼吸效果，不伪装成真实视频生成。
- `labels` 开关显示/隐藏语义锚点；标签数据不依赖图片内文字。
- 搜索支持点击提交按钮或回车提交；回车路径跳过输入法组合态。
- 搜索、上传图片、拖拽图片、分享、帮助均可操作。

## 响应式验收

- 390px：浏览器外壳不横向溢出，搜索框、图标和底部控制仍可点击。
- 760px 以下：窗口圆角和工具栏收紧；解释面板贴右下，打开时淡出底部场景文案，避免信息重叠。
- 桌面：画布保持至少 420px 高，标题/状态/热点层相互不重叠。

## 状态细节

- 初始和完成跳转时加载提示使用 `hidden` 属性，并由 `.loading-state[hidden]` 明确移除布局。
- 面板内的关闭和进入按钮会阻止事件冒泡，避免触发底层画布的二次跳转。
