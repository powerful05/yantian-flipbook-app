# 盐田 Flipbook Bug 清单

日期：2026-09-03

## YTF-QA-001 非 MVP 热点解释面板无法稳定查看

- 严重度：S2 / 中
- 状态：待产品确认后修复
- 范围：默认搜索生成页面
- 前置：以禁付费 Mock 模式打开首页并搜索“盐田港”。
- 步骤：点击任一可见热点，例如“集装箱扫描设备”。
- 实际：面板状态先被设置，随后同一次点击立即触发子节点生成；生成完成后面板关闭。用户无法先阅读解释再决定是否“进入这个区域”。
- 期望：若产品保留解释面板，则第一次点击只展示面板，用户点击“进入这个区域”后才导航；若坚持单击即进入，应移除或重新定义面板，避免不可达交互。
- 证据：浏览器中点击后标题直接变为“集装箱扫描设备”，`#anchorPanel` 为 hidden。
- 影响：不阻塞热点链路，但削弱“可解释”验收，且按钮语义与实际行为不一致。

## YTF-OPS-001 localhost 健康检查可能被系统代理污染

- 严重度：S3 / 低
- 状态：部署脚本已规避，系统环境仍存在
- 前置：环境设置 `HTTP_PROXY`/`HTTPS_PROXY=http://127.0.0.1:7897`，但没有 `NO_PROXY`。
- 步骤：使用默认 `Invoke-WebRequest http://127.0.0.1:<port>/`。
- 实际：请求经代理返回 502，容易误判服务不可用。
- 期望：localhost 直接连接。
- 处理：`deploy-local.ps1` 设置 `NO_PROXY`，并使用 `curl.exe --noproxy '*'`。

## YTF-OPS-002 默认端口可能与历史进程冲突

- 严重度：S3 / 低
- 状态：部署脚本已检测并阻断覆盖
- 证据：本次检查发现 4173、4189、4192、4193 已有监听；旧日志记录过 `EADDRINUSE 127.0.0.1:4189`。
- 风险：未核对进程就重复启动会失败，也可能误测旧版本。
- 处理：使用独立端口；脚本启动前输出占用进程 ID 并终止部署，不自动杀进程。
