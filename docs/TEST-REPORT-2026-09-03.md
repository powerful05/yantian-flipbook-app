## 1. 验收标准

- 用户：需要探索盐田地点的演示用户。
- 任务：搜索一个地点，在首屏识别目标，并通过有效语义热点进入下一级。
- 成功：搜索结果标题与查询一致；热点位置互异且可点击；子节点保持热点目标；返回和刷新恢复上下文；失败不伪装成功。
- 失败：串题、热点集中在中心、点击无响应、错误静默回退、动效失败导致静态页不可用、刷新丢失当前节点。
- 事实边界：本报告验证本地 Mock、接口契约和既有 MVP 构图；未验证真实地点外观、生产部署、付费模型账户权限或在线 Wan 生成。

## 5. 运维结论

- 本地运行入口：`powershell -ExecutionPolicy Bypass -File .\scripts\deploy-local.ps1 -Port 4194`。
- 默认脚本禁用付费请求，执行 `npm ci`、自动测试、P0 数据校验、端口检查和健康检查。
- 本机存在 `HTTP_PROXY`/`HTTPS_PROXY`；Windows PowerShell 5.1 的 Web cmdlet 没有 `-NoProxy`。本地探测应使用 `curl.exe --noproxy '*'`，或设置 `NO_PROXY=127.0.0.1,localhost`。
- 发现历史服务占用 4173、4189、4192、4193。部署脚本会拒绝覆盖既有监听者，不会主动终止未知进程。

## 6. 发布准入

- 本地演示：**准入**，前提是明确标注 LOCAL MOCK / MVP，使用隔离端口并保留静态降级。

- 生产环境：**不准入**。必须先完成持久化、生产部署、真实媒体验证、失败重试及成本监控。
