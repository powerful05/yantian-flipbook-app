# 空画布与节点上下文变更记录

> 日期：2026-08-29  
> 范围：盐田 Flipbook 本地 PoC  
> 状态：已完成本地 Mock 与 4189 页面验收，未发起付费模型调用

## 变更目的

让根路径首次打开时遵循 Flipbook 式空状态，并让搜索框反映当前视觉节点，形成可连续深入的父节点 -> 子节点路径。

## 文件范围

- 修改 `index.html`：清空搜索框默认值，移除首屏盐田港标题/演示状态，增加空画布提示和等待态元数据。
- 修改 `app.js`：增加空画布状态、空状态点击保护、查询上下文快照/恢复、节点 ID URL 状态，以及统一锚点继续探索入口。
- 修改 `styles.css`：增加空状态的视觉层，并将热点 hover 从尺寸动画改为 transform，避免布局重排。

## 前后行为

变更前：根路径自动显示盐田港 Mock 地图、6 个热点和预填搜索词；生成子节点后搜索框仍停留在上一层查询。

变更后：

- 根路径搜索框为空，画布无预置地图/热点，显示官方式英文空状态提示。
- 搜索成功后，输入框更新为当前节点标题；继续进入子节点后再次更新为子节点标题。
- 历史返回同时恢复画面、节点和搜索上下文。
- 生成节点的标签解释面板与画布探索共用同一请求入口，可继续生成更深层节点。
- 空画布点击只聚焦搜索框，不会回退到硬编码盐田港；空首屏生成失败也保留空状态。

## 验证

- `node --check app.js`：通过。
- `npm test`：27/27 通过。
- `npm run validate:dataset`：20 个场景、60 个锚点通过。
- Impeccable detector：无告警。
- 4189 重启后浏览器验收：空输入、`00 anchors`、空画布提示可见。
- 4190 确定性 Mock 浏览器验收：搜索 -> 根节点 -> 子节点 -> 第三层 -> 返回，查询上下文和历史恢复均通过。

## 接口影响

无新增公开接口。现有 SSE 生成请求合同不变；生成节点仍通过 `parent_node_id` 维护父子关系。

## 回滚

仅需恢复 `index.html`、`app.js`、`styles.css` 的本次版本并重启本地服务。本次浏览器验收使用的 4190 Mock 进程不产生云端请求；4189 的云端配置未被改动。
