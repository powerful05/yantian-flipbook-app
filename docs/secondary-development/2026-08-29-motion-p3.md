# Wan 动效 endpoint 修正与 P3 适配记录

> 日期：2026-08-29  
> 范围：盐田 Flipbook 本地 PoC  
> 状态：已完成离线验证，未发起付费模型调用

## 变更目的

修正 Wan 单帧环境动效与首尾帧过渡共用 endpoint 的问题，并把两种任务的请求契约、失败回退和取消行为锁进离线测试。当前服务仍默认使用 Mock，模型请求开关没有开启。

## 已确认的供应商契约

- `wan2.2-kf2v-flash` 首尾帧任务：
  `/api/v1/services/aigc/image2video/video-synthesis`。
- `wan2.6-i2v-flash` 单帧任务：
  `/api/v1/services/aigc/video-generation/video-synthesis`。
- 两类 HTTP 创建请求都使用 `X-DashScope-Async: enable`，随后通过 `/tasks/{task_id}` 轮询。
- 单帧首轮参数为 `resolution=720P`、`duration=2`、`audio=false`，并保留稳定派生的 `seed`。

依据：阿里云百炼官方 [万相-图生视频 API 参考](https://help.aliyun.com/zh/model-studio/image-to-video-api-reference) 与 [万相-首尾帧生视频 API 参考](https://help.aliyun.com/zh/model-studio/image-to-video-by-first-and-last-frame-api-reference)，核验日期为 2026-08-29。

## 文件范围

- 修改 `src/bailian-scene-pipeline.mjs`：增加按 profile 选择的 endpoint 常量；transition 继续使用首尾帧接口，ambient 改用单帧接口。
- 修改 `tests/bailian-scene-pipeline.test.mjs`：精确断言两个 endpoint、请求体和异步头；增加任务失败与 `AbortSignal` 取消测试。
- 修改 `docs/PROJECT-STATUS-2026-08-28.md`：同步 P3 当前状态、已完成能力和剩余缺口。

## 前后行为

变更前：transition 和 ambient 都提交到 `image2video/video-synthesis`；真实 `wan2.6-i2v-flash` 请求会命中错误的服务路径。

变更后：

- transition 使用 `image2video/video-synthesis`，发送 `first_frame_url`、`last_frame_url` 和过渡提示词。
- ambient 使用 `video-generation/video-synthesis`，发送 `img_url` 和 2 秒无声微动参数。
- 任务状态为失败时返回稳定的 `BAILIAN_TASK_FAILED`，保持可重试语义。
- 请求信号取消时返回不可重试的 `GENERATION_ABORTED`，不会继续轮询。
- 已有进程内 motion cache 行为保持不变；本次没有引入数据库或对象存储。

## 接口影响

公开 SSE 合同没有变化。`motion` 事件仍按 `final -> motion:queued -> motion:ready|failed` 发送；变化只发生在服务端向百炼提交动效任务的内部 endpoint 和请求体。

## 部署与回滚

部署无需迁移。重启服务后新任务自动使用修正后的 endpoint；已有 Mock 节点不受影响。

回滚可恢复 `src/bailian-scene-pipeline.mjs`、对应测试和本记录文件，或暂时将 `MOTION_GENERATION_MODE` 设为 `off`。本次没有创建远程任务、写入远程资源或改变计费状态。
